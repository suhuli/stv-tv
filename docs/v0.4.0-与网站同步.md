# v0.4.0 —— 与网站（tv.181.cx）近期更新同步 + 播放器交互重做

网站这段时间做了：同名聚合、巡检健康排序、自动换源 / 上次可播、已看集数。本版本把这些能力搬到 TV 端，并按用户反馈重做了快进/快退交互。

## 一、播放器（用户痛点）

| 问题 | 之前 | 现在 |
|---|---|---|
| 左右键快进「和市面播放器不一样」 | 每按一下立刻 seek 一次 **并弹出控制条**，第二下就变成在按钮间移动焦点；连按时每下都真正 seek，HLS 拉分片卡顿 | 按键只移动**预览位置**（底部大号时间 + 进度条），松手 550ms 后才 seek 一次；长按加速 1×→2×→4×→8× 步长；预览中 **确定** = 立即跳转，**返回** = 取消，**上/下** = 落实后呼出控制条 |
| 播不出来要等三个内核轮完 | 任何错误都 Exo → IJK → 系统 逐个试，网络错误也要等 3 轮 | ExoPlayer 报 IO 类错误（2xxx：网络/403/404/m3u8 拉不到）或 manifest 错误时**跳过内核降级直接换源**；只有解码/格式错误才换内核 |
| 一直转圈 | 没有起播超时 | 内核建好 30 秒仍无画面 → 按源侧失败处理 → 自动换源 |
| 换源全靠手动 | 失败后弹「换源播放」按钮，点了再搜 | **自动换源**：优先用搜索页已聚合的候选（零网络），没有再现搜；按 上次可播 > 巡检可播（延迟低优先）> 未巡检 > 海外受限 > 异常 排序；本次失败过的源排最后；保留集数与进度；一次会话最多 3 次，之后才弹错误 |
| 换源面板看不出哪个源靠谱 | 只有源名 | 源名 + 巡检状态（绿「可播 254ms」/ 黄「海外受限」/ 红「异常」）+ 「上次可播」 |
| 进度轮询在预览时覆盖显示 | — | 预览期间不刷新 positionMs，避免进度条跳回 |

## 二、搜索 / 详情

- **同名聚合**：`groupSearchResults()` 按 `normalizeTitle` 分组，一部片一张卡，卡上「N 个源 · 推荐源名 · 上次可播/推荐」。点卡片进推荐源的详情。
- **详情页「其它源」行**：来自 `SearchGroupCache`（进程内，最近一次搜索的聚合结果），一键切换，用 `popUpTo` 替换当前详情页，返回键直接回搜索结果。
- 详情拉取失败时也列出其它源。
- 来源行显示巡检标签；选集里已看的集打 ✓ 并降低亮度；显示「已看 N 集」。

## 三、巡检接入（`SourceHealthRepository`）

- 读取 `https://tv.181.cx/data/source-health.json`（网站每天 03:00 北京时间由 GitHub Actions 生成），内存 + DataStore 缓存 6 小时，失败 5 分钟后再试。
- 状态推导与网站一致：`api_ok && play_ok` = 可播，`api_ok` = 海外受限（巡检机在海外拉不到片，国内电视一般能播，**只降权不跳过**），否则 = 异常。
- 搜索源列表：异常源直接不搜（剩余不足 3 个时不过滤），其余按健康排序 —— 结果更快出齐。
- 设置页：巡检摘要（N 可播 · N 海外受限 · N 异常 · 时间）+ 每个源一个彩色标签。

## 四、播放记忆（`PlaybackMemory`，对应网站 localStorage 的 lastGoodSource / watchedEpisodes）

- **上次可播**：真正播出画面（播放中且进度 > 2s）时记录 片名 → 源；聚合选源、自动换源、换源面板都优先它。上限 300 部。
- **已看集数**：看到 90% 或播完记为已看；切集 / 播完时也补记。
- 设置页新增「清空播放记忆」。

## 五、首页

- 「剧集」改名「电视剧」；标签顺序与网站一致：热门、综艺、美剧、英剧、韩剧、日剧、国产剧、港剧、日本动画、纪录片。

## 七、需要真机回归的点

1. 快进预览：连按、长按、确定、返回、上/下五种退出路径；IJK / 系统内核下 seek 是否准确。
2. 自动换源：断网 / 换一个已知失效源，确认 30 秒内切走且集数、进度保留；三次后弹错误。
3. 巡检数据首次拉取失败（离线）时搜索是否仍正常（应回退为不过滤）。
4. 详情页「其它源」切换后返回键是否直接回到搜索结果。
